Inputs go to this cell's fitted statistical model: API(t) = P(t) + k·API(t−1), then backscatter = a + b·API. It estimates a radar-backscatter response, not soil moisture, flooding, or water storage.




About LAND MEMORY

 
For each cell LAND MEMORY fits backscatter(dB) = a + b·API for HH and HV, where API(t) = P(t) + k·API(t−1) is a rainfall-history index from IMERG. Direction A compares a new observation with the cell's own history; Direction B compares its slope with similar places.

 
Limits
  • Radar backscatter is not a direct measure of soil moisture or flooding. An unusual value says "investigate", not "why".
    • 
 
  • NISAR repeats about every 12 days and calibrated data begins in June 2026, so histories are short. Check the confidence label.
    • 
 
  • Rainfall is coarse (about 10 km) compared with a 250 m cell. Missing rain is never treated as zero; affected dates are excluded.
    • 
 
  • API decay k is an assumption; see the sensitivity table. Land cover is a broad grouping.
    • 
 
  • The Digital Twin is a statistical prototype, not a physical water model, and is not validated.
    • 
 
  • Cells are analysis areas, not individual farms. Mixed provisional and validated products can look like change.
